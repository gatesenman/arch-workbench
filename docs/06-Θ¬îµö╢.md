## 已知限制
1. 规范校核为简化规则（未覆盖全部条文及例外情形，如袋形走道、不同使用功能的疏散距离差异、地方标准），不替代施工图审查；条文以规范原文为准。
2. 估算单方、其他费费率为示意数据；正式成果应按当地计价依据和 CECA/GC 编审规程编制。
3. 报建材料清单为通用版本，各地工程建设项目审批系统要求不同。
4. 日照间距系数需按地方规定输入；未做日照模拟计算（需专业日照软件）。
5. Word 为 HTML 格式 .doc（Word / WPS 可打开编辑），非 .docx；未套用院标图框 / 公司模板。
6. 未与真实大模型联调；浏览器预览直连部分 API 可能受 CORS 限制，桌面版不受影响。
7. 数据存本机 localStorage，无多人协同、无电子签章；API Key 本机明文保存。
8. Windows 包未签名、默认图标，仅在 Linux 交叉构建，未在真实 Windows 上运行。
