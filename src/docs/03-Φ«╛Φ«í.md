# 03 设计 · UI 规格（v2，角色：UI/UX 设计师）

## 1. 窗口布局（基准 1440×900，最小 1100×700）
```
菜单栏 30px   [Logo] 文件 编辑 视图 智能体 工具 窗口 帮助 ............ [当前项目 下拉]
工具栏 34px   新建项目 导入 导出 | 总览 运行 Word MD 复制 | 资源管理器 输出 属性 ...... 主题 AI设置
主体          项目资源管理器(250) ║ 标签栏 30px / 编辑区 / ═ 输出|问题 面板(170) ║ 属性(280)
状态栏 22px   模式 | 工程编号 名称 | 阶段 | 消息 ............ 未闭合事项 | 累计运行 | 主题 | 时钟
```
- ║ / ═ 为可拖动分隔条，宽高持久化；Ctrl+B / Ctrl+J / 工具栏按钮显隐。
- 资源管理器：搜索框 + 按设计阶段分组的可折叠树，当前阶段文件夹图标为"打开"，节点右侧显示记录/运行数。
- 标签页：图标 + 简称，关闭按钮、中键关闭、右键菜单（关闭 / 关闭其他 / 关闭全部）。

## 2. 编辑区三种视图
1. **表单型**（生成式 / 规则计算）：左 400px 参数表单（标签-控件两列网格，长文本单列；链接图标表示取自项目规划条件），底部"运行（F5）/ 重置"；右侧输出面板（来源徽标、复制、导出 Markdown、导出 Word）。
2. **记录型**（校审、图纸、变更、现场）：工具条（新建、编辑、删除、升版、生成单据、生成汇总、导出 CSV、专业 / 状态筛选）→ 警示条 → 数据网格（单击选中、双击编辑、状态列内联下拉）→ 下部输出面板。
3. **项目总览**：项目抬头、五阶段流程条（已完成 / 当前 / 未开始）、按阶段分组的智能体卡片、未闭合事项、最近成果。

## 3. 视觉规范
- 深色（默认，参考 JetBrains 新 UI）与浅色两套 CSS 变量；12px 微软雅黑 UI；强调色 #3574F0。
- 图标：Remix Icon 本地字体（线性 line 风格为主，状态用 fill：满足=绿色勾、不满足=红色叉、警示=琥珀三角）。
- 来源徽标：AI 实时生成（绿）、本地规则计算 / 项目记录生成（琥珀）、【模拟输出】（紫 + 虚线横幅）。
- 对话框：标题栏 + 两列表单 + 右下"取消 / 确定"，必填红色星号，错误红字提示，Esc 关闭。

## 4. 交付文件格式
| 类型 | 格式 | 说明 |
|---|---|---|
| 报告 / 单据 | .doc | Word 可直接打开，宋体正文、黑体标题、表格框线；√ × △ 替代图标 |
| 文本 | .md | 模拟结果附【模拟输出】声明 |
| 台账 | .csv | UTF-8 BOM，Excel 直接打开 |
| 项目 | .json | 导入 / 导出、备份迁移 |

## v2.1 设计系统升级（"更高级"）
- **字体**：HarmonyOS Sans SC → MiSans → Microsoft YaHei UI → PingFang SC → Noto Sans CJK SC（系统已安装则优先使用，未打包字体文件）；等宽 JetBrains Mono / Cascadia / Consolas；表格数字等宽（tnum）。
- **间距尺度**：4 / 8 / 12 / 16 / 24 / 32；**圆角**：4 / 6 / 8 / 12；**字号**：11 / 12 / 13 / 14 / 16 / 22。
- **色彩**：中性灰阶（深色 #17181B 起、浅色 #F6F7F9 起）+ 唯一强调蓝；1px 半透明发丝线（rgba 7%–14%）；三级阴影 sh1 / sh2 / sh3。
- **无边框标题栏**：Electron `frame:false`，标题栏可拖动、双击最大化，右侧最小化 / 最大化 / 关闭（关闭悬停红色）；浏览器预览时自动隐藏窗口按钮。标题栏中央为命令面板入口（Ctrl K）。
- **命令面板**：毛玻璃遮罩、分组结果、关键字高亮、↑↓ / Enter / Esc。
- **动效**：菜单 / 弹窗 pop、标签与视图淡入、卡片悬停上浮、Toast 滑入；生成时骨架屏 → 逐行流式输出 + 光标；`prefers-reduced-motion` 下全部降为即时。
- **Toast**：成功 / 错误 / 警告 / 信息四态，右下角堆叠最多 4 条，2.6 s 自动消失。
- **空状态**：圆形渐变底 + 虚线环 + Remix 图标 + 标题 + 引导文案。
- **表单**：分组卡片（带图标与规范编号标题）、单位后缀（㎡ / m / % / h / 元/㎡ / 辆/100㎡）、聚焦光环、即时校验与错误提示、运行前整体校验。
- **成果文档卡片**：卡片头（智能体图标、标题、工程编号、时间）、来源徽标、模拟横幅、圆角表格容器（悬停显示"复制表格"，TSV 可贴 Excel）、h4 强调条。
- **总览**：项目抬头 + 4 张 KPI 卡 + 阶段时间线（已完成实心、当前光环、未开始空心）+ 智能体卡片 + 未闭合事项 / 最近成果双栏。
- **键盘**：资源管理器 ↑↓ Enter、总览卡片 Tab / Enter、全局 :focus-visible 焦点环。
