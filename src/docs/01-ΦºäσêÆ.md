# 01 规划 · 产品规划与智能体架构（v2.0，角色：产品经理 / 架构师）

## 1. 定位
**建筑师专属工作台**：面向设计院 / 事务所建筑专业的桌面工作台，按国内设计院工作流程组织 AI 智能体，覆盖 **方案设计 → 初步设计 → 施工图设计 → 施工配合 → 竣工** 全过程。离线可用（规则引擎 + 模板），可接入任意 OpenAI 兼容大模型。

## 2. v2 改版要点（根据用户反馈）
1. 界面改为专业桌面软件形态：菜单栏 + 工具栏 + 项目资源管理器（阶段树）+ 多标签编辑区 + 属性面板 + 输出 / 问题面板 + 状态栏，分隔条可拖动，面板可显隐，标签右键菜单，快捷键。
2. 功能全面对齐国内实务：设计任务书、规划设计条件（用地红线、退线、容积率、建筑密度、绿地率、限高、日照）、经济技术指标表、GB 50016 / GB 50352 / GB 55031 / GB 55019 / GB 50763 / GB 50180 校核、三级校审、建施 / 结施 / 水施 / 暖施 / 电施图号、施工图审查意见回复、工规证等报建清单、投资估算 / 设计概算（工程费用 + 工程建设其他费用 + 预备费）、设计变更单 / 技术核定单、现场服务记录、竣工验收（设计单位工程质量检查报告）。
3. 全部 emoji 替换为本地打包的 **Remix Icon** 字体（src/vendor/remixicon，Apache-2.0，无 CDN）。
4. 用户故事覆盖每项功能的端到端流程，并逐条编写 E2E 测试。

## 3. 智能体清单（15 个）
| 阶段 | 智能体 | 类型 | 主要成果 / 交付 |
|---|---|---|---|
| 方案设计 | 设计任务书分析 | 生成式 | 任务书要点、设计阶段与深度、功能面积配置表、风险、澄清事项 |
| 方案设计 | 规划条件与场地分析 | 规则+生成 | 规划条件表、退线可建范围、计容上限、基底上限、绿地下限、日照间距；**写入项目规划条件** |
| 方案设计 | 概念方案与体量试算 | 规则 | 点式 / 板式 / 围合式比选表（层数、密度、高度、限高判定） |
| 方案设计 | 效果图提示词生成 | 生成式 | MJ / SD 正负提示词、参数 |
| 方案设计 | 方案汇报与沟通 | 生成式 | 汇报提纲、会议纪要、工作联系函、方案设计说明 |
| 初步设计 | 经济技术指标核算 | 规则 | 主要经济技术指标表（与规划条件逐项比对，含机动车 / 非机动车配建） |
| 初步设计 | 投资估算 / 设计概算 | 规则 | 工程费用（估算 4 项 / 概算 10 个单位工程）+ 9 项其他费 + 城市基础设施配套费 + 基本预备费 |
| 初步设计 | 报建资料清单 | 规则 | 工规证 / 方案审查 / 图审送审 / 施工许可材料清单 + 人防、绿建、海绵、装配式专项 |
| 施工图设计 | 规范符合性校核 | 规则 | 防火分类、耐火等级、防火分区、安全出口、疏散距离、消防车道、登高场地、栏杆、净高、踏步、坡道、无障碍出入口、日照标准、日照间距 |
| 施工图设计 | 三级校审 | 记录 | 校对 / 审核 / 审定意见登记、回复闭合、强条拦截出图、校审记录单 |
| 施工图设计 | 图纸目录与图号管理 | 记录 | 建施-01 式图号、图幅 / 比例 / 版次、升版作废、必备图纸检查、折合 A1、图纸目录 |
| 施工图设计 | 施工图审查意见回复 | 规则+生成 | 逐条规范匹配、强条识别、回复与修改图号、签字栏 |
| 施工配合 | 设计变更单 / 技术核定单 | 记录 | SJBG-建-001 / JSHD-001 编号、标准单据（含建设 / 监理 / 施工签字栏）、汇总与造价影响合计 |
| 施工配合 | 现场服务记录 | 记录 | XCFW-001 编号、现场服务记录表、周报 |
| 竣工 | 竣工验收（设计单位） | 汇总 | 汇总图纸、校审、变更、现场记录；未闭合拦截；设计单位工程质量检查报告 |

## 4. 架构
```
Electron 主进程 src/main.js ── 加载 ──> src/index.html（亦可浏览器直接打开）
 ├─ vendor/remixicon      本地图标字体
 ├─ agents.js（UMD）      业务规则 + 智能体定义（fields / prompt / mock / columns / summary / doc）
 │    sunlightStandard · siteCapacity · massingOptions · calcIndicators · fireClass · checkCompliance
 │    estimateCost · drawingNo · drawingCheck · planCheckReply · permitList · recordNo · md · callLLM · runAgent
 └─ app.js                桌面 UI：菜单 / 工具栏 / 树 / 标签 / 属性 / 输出问题面板 / 状态栏 / 对话框 / 导出
```
- 数据：localStorage `aw-db-v2`，按项目保存 runs（成果历史）、plan（规划条件）、records（drawings / review / change / service）。
- 交付：Word（.doc，HTML 格式 Word 可直接打开编辑）、Markdown、CSV（UTF-8 BOM，Excel 可直接打开）、项目 JSON。
- 来源标识：AI 实时生成 / 本地规则计算 / 项目记录生成 / 【模拟输出】。
