## 命令

- 桌面：`npm install && npm start`
- 测试：`npx playwright install chromium && npm test`；截图：`SHOTS=1 npm test`

- 打包：`npm run dist:win`

## 关键实现
- 智能体声明式定义：表单型 `fields/prompt/mock`（`plan:` 字段自动取项目规划条件，`proj:` 取项目属性），记录型 `columns/summary/doc`。
- 规则计算（指标、规范、估算概算、体量、场地容量、图号）均为纯函数，单测覆盖；接入 AI 后默认仍本地计算（可在设置中改为交由 AI）。
- `runAgent`：AI 模式调用 `/chat/completions`，失败回退模拟并记录错误；系统提示词约束规范引用与中文实务。
- Word 导出：HTML + Office 命名空间，`application/msword`。

## 开发中发现并修复的问题
1. 记录表状态内联修改后警示条不刷新 → 修改后重绘编辑区（US-12 发现）。
2. 日期用 `toISOString()` 取 UTC，北京时间凌晨显示为前一天 → 改为本地日期（截图核查发现）。
3. 建施必备图纸检查对"建筑设计总说明"误报缺"设计说明" → 改为正则匹配（总平面 / 平面图区分）。
4. 窄屏下输出面板标题竖排换行 → 标题与按钮不换行、来源说明省略显示。

## v2.2 AI 主导架构
- `src/pilot.js`（UMD）：
  - PIPELINE 共 11 步：任务书 → 场地 → 体量 → 指标 → 估算 → 规范 → 三级校审 → 图纸目录 → 图审回复 → 施工配合 → 竣工。
  - 每一步的流程：`aiFill`（AI 依据上下文和前序摘要，按 JSON 填写参数；离线时由 `heuristicFill` 按规则推算）→ `runAgent`（规则型先调用本地规则工具，AI 再撰写引用该结果的说明）→ 检查点。
  - `aiRecords`：AI 草拟记录，编号由规则 `drawingNo`/`recordNo` 生成，并经 `verifyRecords`（如 drawingCheck、强条闭合检查）校验。
  - 对话助手：`chatMessages`。
- `src/agents.js`：
  - 支持 SSE 流式。
  - 首字超时，总超时为首字超时的 5 倍。
  - 401/402/429/503 给出中文提示。
  - `buildContext` 注入规划条件、指标、记录和签字信息；`SYSTEM_PROMPT` 要求"禁止编造条文号"并给出"下一步建议"。
- 界面：
  - "AI 自动推进"标签页（Ctrl+P），检查点有两种：每步确认、仅关键节点确认。
  - AI 助手面板（Ctrl+L）。
  - 智能体表单有"AI 填写"，记录页有"AI 草拟"。
  - 设置里有服务商预设、模型列表、流式开关、AI 说明开关和 max tokens。
- 密钥只保存在本机 localStorage，不写入导出文件。测试通过环境变量 `DEEPSEEK_API_KEY` 注入。
